# Linked List

Java linked-list preparation organized into fundamentals and official LeetCode problems.

## Conventions

- Official LeetCode problems use `XXXX-Problem-Name`.
- Implementation exercises without an exact LeetCode equivalent live under `Fundamentals/`.

## Core Patterns

`Pointer Manipulation` • `Fast & Slow Pointers` • `Reversal` • `Cycle Detection` • `Merge` • `Dummy Node` • `In-place Reordering`
