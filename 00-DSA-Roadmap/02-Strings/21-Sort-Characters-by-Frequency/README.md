# Sort Characters by Frequency

## Problem

Sort the characters of a string according to decreasing frequency.

## Approach

Use a HashMap to count the frequency of every character.

Store the unique characters in a list and sort them according to their frequencies.

Append each character to the result according to its frequency.

## Example

Input:

tree

Possible Output:

eert

## Complexity

- Time Complexity: O(n + k log k)
- Space Complexity: O(k)

## Interview Pattern

HashMap / Frequency Sorting
