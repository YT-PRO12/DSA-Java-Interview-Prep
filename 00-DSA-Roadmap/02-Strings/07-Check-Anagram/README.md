# Check Anagram

## Problem

Given two strings, determine whether they are anagrams.

Two strings are anagrams if they contain the same characters with the same frequencies.

## Approach

Convert both strings into character arrays.

Sort both arrays.

If the sorted arrays are equal, the strings are anagrams.

## Example

listen
silent

Output:

true

## Complexity

- Time Complexity: O(n log n)
- Space Complexity: O(n)

## Interview Pattern

Sorting / String
