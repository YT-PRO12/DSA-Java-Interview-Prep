========================================
             SLIDING WINDOW MAXIMUM
========================================

Problem:
Find the maximum element in every window of size K.

Input:
Array = [1, 3, -1, -3, 5, 3, 6, 7]
K = 3

Output:
[3, 3, 5, 5, 6, 7]

Explanation:

[1, 3, -1] -> 3
[3, -1, -3] -> 3
[-1, -3, 5] -> 5
[-3, 5, 3] -> 5
[5, 3, 6] -> 6
[3, 6, 7] -> 7
