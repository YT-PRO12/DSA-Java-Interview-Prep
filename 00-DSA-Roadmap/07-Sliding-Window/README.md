# Sliding Window

A focused collection of fixed-window, variable-window, and monotonic-deque problems in Java.

## Patterns

| Pattern | Typical Use |
|---|---|
| Fixed Window | constant-size subarray or substring |
| Variable Window | minimum/maximum range satisfying a condition |
| Frequency Window | substring constraints and character counts |
| Monotonic Deque | window maximum/minimum in linear time |

## Progression

```text
Fixed Window
    ↓
Variable Window
    ↓
Frequency-Constrained Window
    ↓
Monotonic Deque
```
