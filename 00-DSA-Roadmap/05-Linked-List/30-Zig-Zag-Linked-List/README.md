# Zig Zag Linked List

## Problem
Rearrange a linked list in zig-zag order by alternately taking nodes from the beginning and end.

## Approach
Find the middle, reverse the second half and merge the two halves alternately.

## Complexity
- Time: O(n)
- Space: O(1)

## Pattern
Midpoint + Reversal + Alternating Merge
