# Two Sum II

## Problem Statement

Given a **sorted** integer array `numbers` and an integer `target`, find two numbers whose sum equals `target`.

Return the **1-based indices** of the two numbers.

## Example

Input:

`numbers = [2, 7, 11, 15]`
`target = 9`

Output:

`[1, 2]`

Because:

```text
2 + 7 = 9
