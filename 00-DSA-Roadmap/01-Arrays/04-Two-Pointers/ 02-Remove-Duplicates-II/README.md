# Remove Duplicates from Sorted Array II

## Problem Statement

Given a sorted integer array, remove duplicates in-place so that each element appears **at most twice**.

Return the new length of the modified array.

## Example

Input:

`nums = [1, 1, 1, 2, 2, 3]`

Output:

`5`

The modified array is:

```text
[1, 1, 2, 2, 3]
