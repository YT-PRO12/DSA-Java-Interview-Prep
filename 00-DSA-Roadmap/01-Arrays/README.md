
# Arrays

Arrays are one of the fundamental data structures in DSA.

This section covers array manipulation, searching, traversal,
subarrays, and common interview patterns.

## Concepts

- Array traversal
- Minimum and maximum
- Second largest element
- Reversing arrays
- Frequency counting
- Prefix sums
- Kadane's Algorithm
- Two-pointer techniques
- Sorting-based problems

Understand the underlying pattern behind each problem rather than
memorizing individual solutions.
