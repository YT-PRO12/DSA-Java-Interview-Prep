# Arrays

This section covers important Array concepts and interview problems in Java. The problems are organized by patterns so that the focus is on understanding problem-solving techniques rather than only collecting solutions.

## Structure

```text
01-Arrays/
│
├── 01-Basics/
├── 02-Array-Manipulation/
├── 03-Hashing/
├── 04-Two-Pointers/
├── 05-Prefix-Sum/
├── 06-Kadane-Pattern/
├── 07-Sorting-Based/
└── 08-Interview-Problems/
```

## 01. Basics

Fundamental problems for building a strong understanding of arrays.

* Largest Element
* Second Largest Element
* Check if Array is Sorted
* Reverse Array
* Move Zeroes

## 02. Array Manipulation

Problems involving modifying, rotating, rearranging, and transforming arrays.

## 03. Hashing

Problems where HashMap or HashSet can improve lookup and frequency-based operations.

Key problems include:

* Two Sum
* Majority Element
* Longest Consecutive Sequence
* Frequency Counting
* Subarray Sum

## 04. Two Pointers

Problems where two indices are used to efficiently process an array.

Key problems include:

* Two Sum II
* 3Sum
* Container With Most Water
* Trapping Rain Water

## 05. Prefix Sum

Problems involving cumulative sums to answer range and subarray-related queries efficiently.

Key concepts:

* Prefix Sum
* Range Sum
* Equilibrium Index
* Subarray Sum

## 06. Kadane Pattern

Problems involving maximum or minimum subarray sums.

Key problems include:

* Maximum Subarray
* Maximum Circular Subarray
* Maximum Subarray Variations

## 07. Sorting-Based

Problems where sorting is used as part of the solution or helps simplify the problem.

Key problems include:

* Sort 0s, 1s and 2s
* Merge Sorted Arrays
* Merge Intervals
* Next Permutation

## 08. Interview Problems

More important and comparatively challenging array problems that combine multiple concepts.

Examples include:

* Best Time to Buy and Sell Stock
* Product of Array Except Self
* Majority Element II
* Rearrange Array by Sign
* Leaders in an Array
* Maximum Product Subarray

## Problem Format

Each problem is documented with:

* Problem Statement
* Example
* Approach
* Brute Force Approach when relevant
* Optimized Approach
* Java Implementation
* Time Complexity
* Space Complexity
* Key Learning

## Patterns Covered

| Pattern               | Purpose                               |
| --------------------- | ------------------------------------- |
| Array Traversal       | Process elements efficiently          |
| Two Pointers          | Reduce unnecessary comparisons        |
| Hashing               | Fast lookup and frequency tracking    |
| Prefix Sum            | Efficient range/subarray calculations |
| Kadane's Algorithm    | Maximum subarray problems             |
| Sorting               | Simplify ordering-based problems      |
| In-Place Manipulation | Modify arrays with O(1) extra space   |

## Goal

The goal of this section is to understand common Array patterns, improve problem-solving skills, and build a strong foundation for more advanced DSA topics.

**Language:** Java
