# Arrays

A curated Java interview-preparation catalog covering array fundamentals and LeetCode problems.

## Conventions

- Official LeetCode problems use the format `XXXX-Problem-Name`.
- Core exercises without an exact LeetCode equivalent are kept under `Fundamentals/`.
- Existing solution code and problem notes are preserved; this organization only standardizes navigation.

## Core Patterns

`Traversal` • `Two Pointers` • `Hashing` • `Kadane's Algorithm` • `Prefix Sum` • `Sorting` • `Intervals` • `Matrix` • `Rotated Arrays`

## Interview Progression

```text
Array Fundamentals
      ↓
Hashing / Counting
      ↓
Two Pointers
      ↓
Prefix Sum / Kadane
      ↓
Sorting / Intervals
      ↓
Matrix Problems
      ↓
Rotated Sorted Arrays
      ↓
Advanced Two-Pointer Problems
```
