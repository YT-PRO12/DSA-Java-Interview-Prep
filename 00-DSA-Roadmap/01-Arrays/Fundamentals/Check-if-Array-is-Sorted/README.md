# Check if Array is Sorted

## Problem

Given an array of integers, check whether the array is sorted in non-decreasing order.

## Approach

Start from the second element and compare each element with the previous element.

If any element is smaller than the previous element, the array is not sorted.

Otherwise, the array is sorted.

## Example

Input:
[1, 2, 3, 4, 5]

Output:
Array is sorted: true

## Complexity

- Time Complexity: O(n)
- Space Complexity: O(1)
