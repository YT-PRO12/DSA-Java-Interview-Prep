# Linear Search

## Problem

Given an array and a target element, find the index of the target element.

If the element is not present, return `-1`.

## Approach

Traverse the array from left to right.

For every element, compare it with the target.

If the element matches the target, return its index.

If the complete array is searched without finding the target, return `-1`.

## Example

Input:
[10, 25, 7, 40, 15]

Target:
40

Output:
Element found at index: 3

## Complexity

- Time Complexity: O(n)
- Space Complexity: O(1)

## Interview Pattern

Array Traversal / Searching
