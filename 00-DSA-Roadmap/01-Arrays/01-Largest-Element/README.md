# Largest Element in an Array

## Problem

Given an array of integers, find the largest element.

## Approach

Start with the first element as the largest.

Traverse the remaining elements.

If the current element is greater than the current largest,
update the largest value.

## Example

Input:

[10, 5, 20, 8, 15]

Output:

20

## Complexity

- Time: O(n)
- Space: O(1)

## Interview Pattern

Array Traversal
