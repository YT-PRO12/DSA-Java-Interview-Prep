# Array Basics

This section covers the fundamental Array problems required to build a strong foundation in Data Structures and Algorithms.

The focus is on understanding array traversal, basic manipulation, and efficient in-place operations.

## Problems

| #  | Problem                  | Main Concept          | Difficulty |
| -- | ------------------------ | --------------------- | ---------- |
| 01 | Largest Element          | Array Traversal       | Easy       |
| 02 | Second Largest Element   | Single Traversal      | Easy       |
| 03 | Reverse Array            | Two Pointers          | Easy       |
| 04 | Move Zeroes              | In-Place Manipulation | Easy       |
| 05 | Check if Array is Sorted | Array Traversal       | Easy       |

## Concepts Covered

* Array traversal
* Comparing elements
* Maintaining variables during traversal
* Two-pointer technique
* In-place array manipulation
* Preserving relative order
* Time and space complexity

## Learning Approach

For each problem, the solution focuses on:

1. Understanding the problem
2. Identifying the simplest approach
3. Improving the approach when possible
4. Implementing the solution in Java
5. Analyzing time and space complexity
6. Understanding the underlying pattern

## Goal

The goal of this section is to build confidence with basic array operations before moving to more advanced patterns such as hashing, two pointers, prefix sums, Kadane's Algorithm, and sorting-based problems.

**Language:** Java
