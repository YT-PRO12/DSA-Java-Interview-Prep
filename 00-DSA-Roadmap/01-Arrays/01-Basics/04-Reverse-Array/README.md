Reverse Array

Problem Statement

Given an integer array, reverse its elements in-place.

Example

Input: [1, 2, 3, 4, 5]
Output: [5, 4, 3, 2, 1]

Approach

Use the two-pointer technique:

Start one pointer at the beginning.

Start another pointer at the end.

Swap the elements.

Move both pointers toward the center.

Optimized Approach

The array is reversed in-place without creating another array.

Java Implementation

See ReverseArray.java.

Complexity

Time: O(n)

Space: O(1)

Key Learning

Two pointers are useful for in-place array transformations.
