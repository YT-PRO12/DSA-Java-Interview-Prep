# Array Manipulation

This section focuses on modifying and rearranging arrays efficiently while maintaining the required order or structure.

## Problems

| #  | Problem                             | Main Concept          | Difficulty |
| -- | ----------------------------------- | --------------------- | ---------- |
| 01 | Left Rotate Array                   | Array Manipulation    | Easy       |
| 02 | Right Rotate Array                  | Array Manipulation    | Easy       |
| 03 | Rotate Array by K Positions         | Reversal Technique    | Medium     |
| 04 | Remove Duplicates from Sorted Array | Two Pointers          | Easy       |
| 05 | Missing Number                      | Mathematical Approach | Easy       |

## Concepts Covered

* Array rotation
* In-place modification
* Reversal technique
* Two-pointer technique
* Mathematical formulas
* Maintaining element order
* Space-efficient array operations

## Learning Approach

For each problem, the focus is on:

1. Understanding the required array transformation.
2. Identifying a straightforward approach.
3. Finding a more efficient solution where possible.
4. Implementing the solution in Java.
5. Analyzing time and space complexity.
6. Understanding the pattern behind the solution.

## Goal

The goal of this section is to become comfortable with modifying arrays in-place and recognizing common techniques such as reversal and two pointers.

These techniques will also be useful in later sections involving hashing, sliding window, binary search, and other DSA patterns.

**Language:** Java
