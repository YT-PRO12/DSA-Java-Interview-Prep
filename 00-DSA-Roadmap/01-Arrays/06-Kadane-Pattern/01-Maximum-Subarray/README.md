
# Maximum Subarray

## Problem Statement

Given an integer array `nums`, find the contiguous subarray with the largest sum and return its sum.

The subarray must contain at least one element.

## Example

Input:

`nums = [-2, 1, -3, 4, -1, 2, 1, -5, 4]`

Output:

`6`

The maximum subarray is:

```text
[4, -1, 2, 1]
