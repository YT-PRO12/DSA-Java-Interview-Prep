# Maximum Product Subarray

## Problem Statement

Given an integer array `nums`, find the contiguous subarray that has the largest product and return the product.

## Example

Input:

`nums = [2, 3, -2, 4]`

Output:

`6`

The maximum product subarray is:

```text
[2, 3]
