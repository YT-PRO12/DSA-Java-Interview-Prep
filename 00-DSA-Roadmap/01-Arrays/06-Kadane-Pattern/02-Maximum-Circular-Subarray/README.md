# Maximum Circular Subarray

## Problem Statement

Given a circular integer array `nums`, find the maximum possible sum of a non-empty subarray.

In a circular array, the subarray can wrap from the end of the array back to the beginning.

## Example

Input:

`nums = [5, -3, 5]`

Output:

`10`

The maximum circular subarray is:

```text
[5, 5]
