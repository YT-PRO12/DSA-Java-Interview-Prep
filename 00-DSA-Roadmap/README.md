# DSA Roadmap

This repository is organized for Java interview preparation with a consistent naming convention.

## Structure

```text
00-DSA-Roadmap/
├── 01-Arrays/
├── 02-Strings/
├── 03-Sliding-Window/
├── 04-Binary-Search/
├── 05-Linked-List/
└── 06-Stacks-Queue/
```

## Naming Standard

Official LeetCode problems:

```text
XXXX-Problem-Name/
```

Examples:

```text
0001-Two-Sum
0141-Linked-List-Cycle
0239-Sliding-Window-Maximum
0739-Daily-Temperatures
```

Problems that are useful DSA fundamentals but do not have an exact LeetCode equivalent are kept under a `Fundamentals/` directory instead of assigning a fake problem number.

## Learning Philosophy

```text
Understand
   ↓
Identify Pattern
   ↓
Implement in Java
   ↓
Analyze Complexity
   ↓
Dry Run
   ↓
Optimize
```
